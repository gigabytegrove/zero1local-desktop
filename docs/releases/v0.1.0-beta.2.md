# Zero1Local Desktop v0.1.0-beta.2 — updater integration

**Release status: source candidate.** Do not publish before new Linux/Windows binaries are built from the exact tagged commit, validated with their SHA-256 manifest, and the app's updater UI is smoke-tested. The tag must reference the final source commit including desktop/go.sum.

## Improvements

- Added an operator-controlled **Settings → Software updates** section and system-tray **Check for updates** action.
- Uses the official Wails v3.0.0 GitHub Releases provider configured for beta releases and a sibling SHA256SUMS file.
- Strict asset matcher selects only a dedicated one-entry updater bundle for the running OS/architecture; it cannot accidentally select the .deb, the user-facing multi-entry Windows ZIP or a different OS build.
- Wails handles download progress, checksum verification, staged replacement and restart confirmation for writable portable installations.
- Package-managed Debian Linux installs get an in-app download of the newer .deb with SHA-256 verification, saved to the user's Downloads folder; the operator installs using their package manager. This prevents bypassing dpkg and root permission boundaries.
- Prevents simultaneous native update checks; reports current version, beta channel, supported mode and errors in Settings.
- Updater window uses the Zero1Local light and dark theme values, not an unrelated color scheme.
- No scheduled forced checks, automatic install, remote NAS changes or privilege-elevating background service.

## Limitations

- v0.1.0-beta.1 users must **manually install this release** because that initial executable lacks the updater.
- SHA256SUMS is integrity checking tied to GitHub TLS, not an independent publisher signature; Ed25519 signing is required before a future stable release.
- Self-upgrade across versions cannot be end-to-end proven until a newer tagged release than the installed updater-enabled build exists.
- Writable portable Windows/Linux binaries use Wails replacement; system-managed Linux packages require manual package-manager installation after verified download.
- No compiled or signed macOS bundle is included; Windows .exe is portable, not MSI or a signed installer.
- Source/build verification and actual on-desktop updater acceptance are separate release gates.
