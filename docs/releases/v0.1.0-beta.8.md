# Zero1Local Desktop v0.1.0-beta.8 — November 2026 security rebuild

This source-only maintenance release candidate retains the beta.7 application features, original Zero1Local branding, NAS sign-in, file handling, native mapping, OS keyring, and user-controlled desktop update lifecycle.

- Upgrade portable Go and Wails desktop module build requirements to Go 1.26.11 (security-patched Go 1.26 branch).
- Rebuild all Linux AMD64/Windows AMD64 binaries and Debian packaging from this exact commit, embedding `main.currentVersion=0.1.0-beta.8`.
- Publish only after portable/frontend race tests, Wails native tests/vet, platform build verification and SHA256SUMS succeed. Exact Linux amd64 .deb/.tar.gz and Windows amd64 .zip are required alongside the two single-entry updater bundles. No Windows GUI acceptance is implied by cross-compilation alone.
- Never replace existing v0.1.0-beta.7 release assets. Preserve the existing local user preferences and NAS configuration.

Build and publish are intentionally local-only per `docs/RELEASING.md`. Do not create a GitHub Release before verifying all asset bytes and source identity.
