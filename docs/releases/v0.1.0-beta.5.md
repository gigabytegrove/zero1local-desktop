# Zero1Local Desktop v0.1.0-beta.5 — NAS-first desktop layout

This prerelease responds to the complete 929-frame review of the November 12, 2026 desktop screencast.

### Fixed
- Add NAS no longer inserts a browser PointerEvent into its address field.
- File Manager and NAS management screens no longer print a literal \`null\`.
- Initial loading screens no longer compete with duplicate manual loading buttons.
- Verified SMB and NFS folders are presented before advanced manual connection fields.

### New desktop layout
- Persistent NAS selector and administrator session status in the top bar.
- Appliance-first command workspace, compact mapping summary and direct file/share/storage/task actions.
- Explicit appliance directory with sign-in/out, version, management and selection controls.
- Expandable NAS management sidebar to keep primary file/share/drives tasks visible without endless scrolling.
- Capacity meters with human-readable byte units, RAID inventory and optional raw diagnostic text.
- Updated responsive behavior and keyboard focus affordances using original Zero1Local colors and brand assets.

### Engineering and security
- Retains per-NAS memory-only administrator sessions, MFA, local origin/CSRF rules and NAS-authorized file operations.
- Retains the GitHub Releases updater and the source provenance contract.
- Built packages are a **beta** until they have passed all automated checks; real Windows/Linux UI and NAS acceptance still required.
