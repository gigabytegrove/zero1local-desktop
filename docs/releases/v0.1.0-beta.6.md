# Zero1Local Desktop v0.1.0-beta.6 — Per-NAS workspaces and remembered sign-in

### Navigation and organization
- Opens on **All NAS devices**, not an implicit default appliance
- Selecting a device enters that NAS's own Overview, File Manager, Shared Folders, Mapped Drives and management pages
- NAS workspace breadcrumb and fast device switcher; device-specific navigation is hidden outside a selected NAS
- Only the selected appliance's mapped drives are shown on its drive page
- Device status, saved sign-in preference and mapped-drive reconnect state are visible where relevant

### Per-NAS administrator sign-in
- Each NAS independently offers session-only sign-in (default) or opt-in **Keep me signed in**
- Native OS vault integration: Windows Credential Manager, macOS Keychain, Linux Secret Service
- On restart, restores an existing valid NAS session (including MFA-approved sessions) before attempting password login
- Automatically reauthenticates when the original NAS cookie expires or is invalidated, subject to NAS policies
- Never stores MFA codes, never disables NAS two-factor authentication, and never writes credentials to app settings
- Sign out removes the vault credential; Stop remembering leaves the current session connected

### Per-share access
- Independent opt-in Windows SMB drive reconnection at Windows sign-in
- Windows, not the Zero1Local companion, owns SMB share credentials
- No claim of Linux/macOS automatic mount support

### Verification
Includes new Go credential persistence and renewal tests plus frontend multi-NAS isolation tests. Beta 6 is a prerelease pending both successful automated build gates and native OS/NAS validation. No Zero1Local NAS server code was modified.
