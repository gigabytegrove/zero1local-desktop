# Zero1Local Desktop v0.1.0-beta.1 — bootstrap beta

Source commit: `d18ab27f459b9151622d8031badf08263e3102b0`

**Native build evidence (dockeradm, November 12, 2026):** owner-provided log confirms Go unit tests, vet, Windows amd64 and Linux amd64 compilation, Debian packaging, ZIP/TAR creation and successful SHA256SUMS verification.

## Available platforms

- Windows amd64: portable ZIP containing an EXE and README.
- Linux amd64: Debian .deb installer and portable .tar.gz.
- Additional dedicated one-entry updater bundles are published for consistent release asset naming, though this bootstrap app **does not itself contain an updater**.
- macOS is not built.

## Known limitations

Early beta. In-app management still opens in the system browser. Linux/Windows native runtime, tray, mounted-drive behavior and ACL workflows remain unqualified on target devices. Windows NFS and macOS NFS not implemented. Automatic reconnect and startup preferences remain incomplete. No promise of production readiness.

## Upgrading

This build does not self-update; install the first updater-capable v0.1.0-beta.2 release manually once it is available. Subsequent portable builds use the explicit in-app updater. Linux Debian installs use verified package downloads and manual package-manager upgrades.

The repository is public; this release does not disclose credentials or private Zero1Local NAS source code.
